Zo maak je een journaal

Van gemergde pull requests naar een uitzending die iedereen begrijpt, in drie stappen.

  1. 1Laat Claude het concept makenClaude haalt via GitHub de gemergde PR’s op en schrijft journaal-concept.json.
  2. 2Importeer het conceptDe app controleert het bestand en zegt precies wat er mis is als het niet klopt.
  3. 3Redigeer en zend uitPas koppen aan, keur goed of sluit uit, en start de uitzending.

DE KNOPPEN

  • Concept importeren: laad journaal-concept.json. Een nieuw bestand vervangt je huidige werk pas na bevestiging.
  • Goedkeuren / Uitsluiten: bepaal wat er wordt uitgezonden.
  • Bewerken: pas kop en uitleg aan, met Opslaan of Annuleren.
  • Bron openen: bekijk de pull request op GitHub in een nieuw tabblad.
  • Start uitzending: volledig scherm, één bericht tegelijk. Volgende met de knop, pijltje rechts of vegen; Esc sluit af.
  • Journaal exporteren: sla het nagekeken journaal op als bestand.
