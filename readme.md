# Release-omroeper

Zet samengevoegde GitHub-pull requests om in een begrijpelijk, speels nieuwsjournaal.

## Eerste versie
1. Een conceptbestand met maximaal vijf nieuwsberichten inladen.
2. Berichten aanpassen, goedkeuren of uitsluiten.
3. Goedgekeurde berichten presenteren als nieuwsuitzending.

## Werkafspraken
- Lokaal ontwikkelen, testen en accepteren op test, daarna naar productie.
- Testen tijdens het bouwen, met bewijs per geplande teststap.
- Elk nieuwsbericht verwijst naar de oorspronkelijke pull request.
- Samengevoegd betekent niet automatisch gepubliceerd.
- Geen wachtwoorden of tokens in Git.
